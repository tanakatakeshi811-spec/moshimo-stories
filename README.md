# もしも〇〇ストーリー

「もしも」の世界線を描く、縦型ショート動画のシリーズサイトです。
ストーリーを選ぶと、第1話から順番に見られます（最後まで見ると次の話へ自動で進みます）。

**サイト：** https://tanakatakeshi811-spec.github.io/moshimo-stories/

## 公開中のストーリー

| ストーリー | 状況 |
|---|---|
| もしもオウム真理教が生き残っていたら | 完結（全5話） |
| もしも「明日の日記」があと3日分しかなかったら | 連載中（全3話中 1話公開） |

## 新しい話の追加方法

1. 動画を `videos/<ストーリーID>/epNN.mp4` に置く（1ファイル50MB未満を目安）
2. サムネイル（720×1280のJPEG）を `posters/<ストーリーID>/epNN.jpg` に置く
3. `index.html` の `STORIES` の `episodes` に1行追加（`soon: true` を外す）

```js
{ no: 4, title: "追跡", src: "videos/aum/ep04.mp4", poster: "posters/aum/ep04.jpg", dur: "2:10", desc: "…" },
```

新しいストーリーは `STORIES` に作品ごと追加します（1話の長さを変えたいときは、作品に `eplen: "約3〜4分"` のように書きます）。
